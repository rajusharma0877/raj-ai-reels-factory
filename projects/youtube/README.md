# YouTube Documentary Factory

Two original illustrated-history channels, managed from this repository:

- `hindi`: Hindi narration and metadata for India.
- `english`: English narration and metadata for an international audience.

## Format

10–15 minute illustrated historical documentaries told from the perspective of ordinary people in the ancient world. Initial focus: everyday life in Ancient Rome.

The reference channel is for format research only. Do not copy its scripts, narration, thumbnails, or images. Every episode must use original research, writing, visual prompts, and assets.

## Production stages

1. Choose a topic and a distinct story angle.
2. Research primary/credible historical sources; record uncertainty and disputed claims.
3. Write an original 10–15 minute script for the selected language.
4. Split the script into timed visual beats and create image prompts.
5. Generate narration and visuals with free-tier tools where available.
6. Assemble a 16:9 video, add subtitles, music with valid usage rights, and thumbnail.
7. Run factual, copyright, audio, and visual QA.
8. Export a review package. Publishing remains manual until explicitly enabled.

## Cost policy

No paid APIs, subscriptions, credit-card trials, or local AI models are assumed. Provider free tiers change; check their current quotas and terms before use. Never put API keys in this repository. Use GitHub Actions secrets for credentials.

## Channel separation

Hindi and English are separate outputs, not literal machine translations. Adapt examples, hooks, pacing, titles, and descriptions for each audience while keeping the underlying historical facts consistent.

## First pilot

Build and review one complete 10–15 minute episode before attempting 1–2 uploads per day. A daily target is a later scaling goal, not a promise of what free services can reliably produce.
