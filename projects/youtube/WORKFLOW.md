# Mobile-first operating workflow

This repository is the control room; production can be triggered from GitHub Actions on a phone.

## Pilot workflow

- Pick one episode topic and angle.
- Create separate Hindi and English episode briefs using the prompt in `prompts/episode-brief.md`.
- Verify claims against cited historical sources before narration.
- Generate narration and visuals using free-tier tools only after checking current limits and usage rights.
- Assemble in a mobile editor if needed; export 1920x1080, 16:9.
- Check pronunciation, subtitle timing, factual claims, visual continuity, audio levels, and thumbnail readability.
- Keep the first export unlisted/private for review. Do not auto-publish.

## Free-tool shortlist to evaluate (availability/quotas can change)

- Research and source collection: public-domain books, museum/university pages, Google Scholar search, Wikimedia Commons (check each file licence).
- Writing/review: ChatGPT free usage or a provider's genuinely free API tier; no paid fallback.
- Narration: device text-to-speech or a verified free quota; listen to the full output before use.
- Images: free-tier image generation only where commercial-use terms permit; otherwise use public-domain/licensed historical images.
- Editing: CapCut mobile free tier or another free editor; check watermark/export limits before committing.
- Captions: editor auto-captions or a free transcription quota, with manual correction.

Do not install unofficial browser extensions or run unknown scripts merely because a tutorial recommends them. Never upload private keys or personal data to third-party tools.
